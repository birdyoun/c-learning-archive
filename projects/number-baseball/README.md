# Number Baseball  

C언어로 만들어진 숫자 야구 콘솔 게임입니다.  

## 게임 룰  

숫자 입력 기회 : 9  
숫자 자릿수 : 4  
숫자 중복 없음  
  
ball : 숫자는 맞지만 위치가 틀림  
strike : 숫자, 위치 전부 맞음  
out : 숫자, 위치 전부 틀림  

출력 방식 : n 스트라이크, m 볼, k 아웃 or 승패 여부  

## 주요 기능  

main.c - 정답 배열을 초기화하고 중복 처리를 한 후, NumberBaseball.c의 함수를 불러오는 역할  
NumberBaseball.c - 실제 기능. 4자리 수를 입력받는 함수와, 정답 배열과 비교하는 함수 두 개로 구성  

## 배운 것  

여러 c와 h로 파일을 나눠보는 감각  
static, extern, 매크로 사용과 남은 버퍼 처리  
랜덤 함수 사용시 아스키 코드를 이용한 형변환
